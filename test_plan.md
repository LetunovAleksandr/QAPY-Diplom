## 2. Перечень автоматизируемых сценариев
1. **Покупка по банковской карте**
   * Успешный платеж
   * Отклонение платежа
2. **Покупка в кредит**
   * Успешная покупка в кредит
   * Отклонение заявки на кредит
3. **Валидация формы**
   * Обязательные поля
   * Некорректный номер карты
   * Истекший срок банковской карты
   * Числа в поле «Владелец»
   * Короткий номер 'CVV'
4. **Взаимодействие с платежным шлюзом**
   * Отправка запроса оплаты банковской картой/кредит
   * Обработка успешного запроса (б.карта/кредит)
   * Обработка отказа (б.карта/кредит)
   * Обработка ошибок
5. **Проверка записи в БД**
   * Создание записи после успешного запроса
   * Корректность статуса
   * Корректность данных

## 3. Перечень инструментов
1. **Pytest** – основной фреймворк для написания и запуска автотестов
2. **Requests** – библиотека для отправки HTTP-запросов и автоматизации API
3. **Selenium** – инструмент для автоматизации тестирования веб-интерфейса в браузере
4. **Allure** – инструмент для формирования наглядных отчетов о результатах тестирования
5. **PyMySQL** – драйвер для подключения python к базе данных MySQL


## 4. Возможные риски
1. **Зависимость окружения.**   
    Автотесты зависят от работоспособности приложения, платежного шлюза и базы данных. При выходе из строя любого из этих элементов тесты упадут. 

2. **Зависимость от состояния БД.** 
Результат тестов может зависеть от данных созданных предыдущими тестами.

3. **Изменение UI.** 
Изменение кода или id элементов может привести к падению автотестов.
