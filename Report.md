# Отчет о проведенном тестировании 


## 1. Краткое описание 
В рамках тестирования было проведено автоматизированное тестирование приложения, 
базы данных и платежного шлюза.   
**Проверялась возможность совершения покупки следующим образом:**  
    - оплата банковской картой   
    - покупка в кредит  

**В ходе тестирования проверялись:**  
    - корректность отображения платежной формы  
    - валидация полей платежной формы  
    - успешная оплата  
    - отклонение платежа  
    - обработка ошибок сервера  
    - корректность отображения сообщений пользователю  
    - создание записей в базе данных  
    - соответствие данных в связанных таблицах базы данных  

**Автоматизированные тесты написаны с использованием:**  
    - Python  
    - Pytest  
    - Selenium  
    - Allure  
    - PyMySQL для проверки данных в базе данных

## 2. Результаты тестирования  
  
Всего было выполнено **20 тест-кейсов**
 
| Результат | Количество | Процент |
|-----------|------------|---------|
| Успешно   | 13         | 65%     |  
| Неуспешно | 7          | 35%     |  
| Всего     | 20         | 100%    |

## 3. Общие рекомендации  
* Исправить обнаруженные дефекты  
* Повторно провести тестирование после исправления дефектов  
* Продолжить проверку данных в базе данных после выполнения оплаты  
* Сохранить автоматизированные тесты для повторного запуска при изменении приложения  
* Использовать Allure для анализа результатов автоматизированного тестирования
