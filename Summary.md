# Summary

## 1. Общая информация  
В рамках дипломного проекта была выполнена автоматизация тестирования веб-приложения с платежным шлюзом.  
  
Цель автоматизации - сократить вермя выполнения повторяющихся проверок и обеспечить возможность регулярного запуска тестов для основных пользовательских сценариев.  
  
Для автоматизации использовались:  
- Python  
- Pytest  
- Selenium  
- Allure  
- SQL   
- MySQl   
- Page object  
- фикстуры Pytest  
- параметризация тестов

## 3. Сработавшие риски  

### Зависимость запуска приложения от готовности базы данных  
В процессе контейнеризации приложения был выявлен риск, связанный с зависимостью
запуска приложения от готовности базы данных. Приложение запускалось сразу после старта контейнера базы данных,
не дожидаясь завершения ее инициализации, вследствии чего не могло установить соединение с БД и завершало работу с ошибкой.  

Для устранения был настроен механизм `healthcheck` для проверки состояния базы данных. Запуск приложения был поставлен в зависимость от успешного прохождения
данной проверки. Это обеспечило запуск приложения только после полной готовности базы данных к работе.

## 4. Общий итог по времени

На выполнение работ было запланировано 19-30 часов с учетом возможных рисков.

Фактически было затрачено 35 часов.  

Превышение запланированного времени связано в основном с ошибками в коде и более длительной, чем планировалось, отладкой автоматизированных
тестов. Дополнительное время также потребовалось для поиска и устранения ошибок и проверки стабильности работы тестов.

В итоге основные запланированные задачи автоматизации были выполнены.
