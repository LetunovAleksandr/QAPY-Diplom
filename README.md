# QAPY-Diplome

Проект автоматизации тестирования веб-приложения с платежным шлюзом.  

В рамках проекта автоматизированы проверки пользовательского интерфейса, API и данных в базе данных.

## Технологии  

* Python 3.14.7
* Pytest
* Selenium WebDriver
* Docker
* Docker Compose
* MySQL
* Allure
* API
* SQL

## Требования 

Перед началом работы необходимо установить:  

* Python 3.14.7;
* Docker Desktop;
* Allure Commandline.

## Установка и запуск  

### 1. Клонирование репозитория  

**Клонировать репозиторий:**  

`git clone https://github.com/LetunovAleksandr/QAPY-Diplom.git`  

**Перейти в директорию проекта:**  

```cmd
cd QAPY-Diplom
```

### 2. Установка зависимостей 

**Установить зависимости из файла `requirements.txt`:***

`pip install -r requirements.txt`

## Запуск приложения  

Компоненты приложения контейнеризированы и запускаются с помощью Docker Compose.

В проекте используются следующие контейнеры:  
* приложение;  
* платежный шлюз  
* MySQL   

Для запуска всех компонентов выполнить из корня проекта:

`docker compose up -d`

После запуска необходимо дождаться полной готовности сервисов.

База данных использует `healthchek`. Запуск приложения зависит от успешной проверки готовности базы данных,
поэтому приложение запускается только после ее инициализации.

## Запуск автоматизированных тестов

Автоматизированные тесты написаны с использованием **Pytets**.

В проекте представлены:

* UI-тесты;  
* API-тесты;  
* тесты проверки данных в базе данных.

### Полный запуск тестов  

Для запуска тестов с браузером Chrome и одновременным 
сохранением резульатов для Allure:

`pytets --browser=chrome --alluredir=results`

После выполнения тестов результаты будут сохранены в директории:

`results/`

## Запуск UI-тестов в разных браузерах

UI-тесты поддерживают следующие браузеры:

* Chrome;
* Firefox;
* Edge;
* Safari.

Для выбора браузера используется параметр:

`--browser`

### Chrome

`pytest --browser=chrome`

### Firefox

`pytest --browser=firefox`

### Edge

`pytest --browser=edge`

### Safari

pytest --browser=safari

Если параметр `--browser` не указан, по умолчанию используется **Chrome**.

Например, для запуска **Firefox** с формированием результатов **Allure**:

`pytest --browser=firefox --alluredir=results`

## Формирование отчета Allure 

В проект интегрирован **Allure Framework** для формирования подробных
отчетов о результатах автоматизированного тестирования.

Для сохранения результатов выполнения тестов необходимо использовать параметр:

`--alluredir=results`

Например:

`pytest --browser=chrome --alluredir=results`

После выполнения тестов для запуска локального отчета **Allure** выполнить:

`allure serve results`

После выполнения команды Allure сформирует отчет и откроет его в браузере.

В отчете отображается информация о:

* количестве выполненных тестов;
* успешных и неуспешных тестах;
* шагах выполнения тестов;
* параметрах тестов;
* ошибках;
* времени выполнения;
* прикрепленных материалах, включая скриншоты.

## Остановка приложения 

После завершения тестирования контейнеры можно остановить командой:

`docker compose down`

Для удаления контейнеров и остановки всех запущенных сервисов
рекомендуется выполнить эту команду после завершения работы с тестовым окружением.

## Основной сценарий запуска

Полный порядок запуска проекта:

```
git clone https://github.com/LetunovAleksandr/QAPY-Diplom.git
cd QAPY-Diplom
pip install -r requirements.txt
pytest --browser=chrome --alluredir=results
allure serve results
docker compose down
```

Таким образом, для запуска автоматизированного тестирования необходимо установить
зависимости, запустить контейнеры, выполнить тесты с помощью **Pytest**
и при необходимости просмотреть результаты выполнения в Allure Report.
